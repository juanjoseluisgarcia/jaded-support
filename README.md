# Jaded support

Questions, bug reports and ideas for **Jaded**, a native Mac app for Jira.

**[Open an issue](https://github.com/juanjoseluisgarcia/jaded-support/issues/new)**

Issues here are public, so please leave out anything private: ticket contents, company details, or screenshots showing personal information.

- [Privacy policy](https://juanjoseluisgarcia.github.io/jaded-site/privacy.html)
- [Terms of service](https://juanjoseluisgarcia.github.io/jaded-site/terms.html)

Jaded's source code is not in this repository.
